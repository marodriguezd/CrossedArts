01 • Alembic Migration Crash (NOT NULL Constraint Violation)

Migration attempts to add a NOT NULL column to the learning_session table without providing a server_default value. In SQLite database containing seed/real data, this triggers a operational crash.

Impact: Migrations are blocked, and databases cannot upgrade to head, triggering application crashes at runtime on insert/update operations. Tests passed because the test fixtures bypassed migrations entirely, calling metadata.create_all() directly.
BEFORE: 
batch_op.add_column(
    sa.Column('inactive_seconds', sa.Integer(), nullable=False)
)
AFTER (Fixed): 
batch_op.add_column(
    sa.Column('inactive_seconds', sa.Integer(), nullable=False, server_default='0')
)
Testing Strategy: Configure a pytest integration test to load migrations via Alembic Programmatic commands on an ephemeral test database before running unit tests.

02 • API Serialization Truncation & NiceGUI State Corruption

The /resources endpoints return base schemas (ResourceBaseResponse), causing Pydantic to silently strip polymorphic subclass fields (difficulty, author, reading_percentage).

Impact: All books load with a progress of 0%. Additionally, editing a course resets its difficulty to BEGINNER because the dialog is initialized with a stripped `None` difficulty, corrupting the database on save.
BEFORE: 
@router.get("", response_model=List[ResourceBaseResponse])
def list_resources(...):
    # Returns base schema only
AFTER (Fixed): 
from typing import Union, Literal

# Use Pydantic discriminator models
class CourseBaseResponse(ResourceBaseResponse):
    type: Literal["course"]
    difficulty: str

@router.get("", response_model=List[Union[CourseBaseResponse, BookBaseResponse]])
def list_resources(...):
    # Preserves specific attributes
Medium Tech Debt / Deprecations Widespread (e.g. backend/app/services/session.py)

03 • Widespread Deprecated `datetime.utcnow()` Warnings

Calling datetime.utcnow() is deprecated in Python 3.12+. Replacing it directly with timezone-aware datetimes will break SQLite queries, resulting in comparison TypeErrors.

Impact: Spamming unit tests with 77 deprecation warnings. Potential application crash in future Python runtime updates where utcnow() is removed.
BEFORE: 
created_at = datetime.utcnow()
AFTER (Fixed): 
from datetime import datetime, timezone

def utc_now_naive():
    return datetime.now(timezone.utc).replace(tzinfo=None)

created_at = utc_now_naive()

High Performance / Networking llm.py | embedding.py | api_client.py

05 • HTTP Client Re-instantiation Pool Exhaustion Anti-pattern

Every request or query initializes an ad-hoc httpx.Client() or httpx.AsyncClient() instance in a context manager block, rather than using connection pooling.

Impact: Each LLM call or API call requires performing new TCP / SSL handshake loops. This slows down requests, leaks socket file descriptors, and can exhaust ephemeral ports on servers under moderate load.
BEFORE: 
async with httpx.AsyncClient() as client:
    response = await client.post(self.api_url, json=payload)
AFTER (Fixed): 
# Initialize client pool on FastAPI lifespan
@asynccontextmanager
async def lifespan(app: FastAPI):
    limits = httpx.Limits(max_keepalive_connections=20)
    app.state.http_client = httpx.AsyncClient(limits=limits)
    yield
    await app.state.http_client.aclose()
Medium Performance / LLM backend/app/services/embedding.py

06 • Sequential HTTP Requests during Ingestion Embeddings

Batch embedding request generation (get_embeddings_batch) processes text strings one by one in sequential client calls instead of using a single batch payload.

Impact: Ingesting books (EPUB / PDF) containing hundreds of pages takes a massive amount of time because of sequential HTTP roundtrips to Ollama.
BEFORE: 
def get_embeddings_batch(self, texts: List[str]):
    return [self.get_embedding(t) for t in texts]
AFTER (Fixed): 
def get_embeddings_batch(self, texts: List[str]):
    # Point endpoint to /api/embed and send all:
    payload = {"model": self.model_name, "input": texts}
    response = client.post(self.api_url, json=payload)
    return response.json().get("embeddings", [])
High Database / Ingestion backend/app/services/extractor.py

07 • SQLite Parameters Cap Violation Hazard (>999 Variables)

Metadata re-indexing queries delete older embedding references in one query statement using a `.in_(old_content_ids)` filter.

Impact: SQLite allows a maximum of 999 parameters. Processing documents with over 999 pages will cause the query to fail, triggering database transaction rollbacks and crash exceptions.
BEFORE: 
db.query(EmbeddingRecord).filter(
    EmbeddingRecord.entity_id.in_(old_content_ids)
).delete()
AFTER (Fixed): 
# Process in chunks of 500
for i in range(0, len(old_content_ids), 500):
    chunk = old_content_ids[i:i+500]
    db.query(EmbeddingRecord).filter(
        EmbeddingRecord.entity_id.in_(chunk)
    ).delete(synchronize_session=False)
High Security backend/app/services/extractor.py

08 • XML External Entity (XXE) Injection Vulnerability

EPUB metadata extraction uses standard Python xml.etree.ElementTree which parses entity references without restrictions.

Impact: Attackers can ingest malicious EPUB files to read sensitive files on the host server (e.g. SSH keys, config databases) or trigger Billion Laughs Denial of Service (DoS) attacks.
BEFORE: 
import xml.etree.ElementTree as ET
root_container = ET.fromstring(container_xml)
AFTER (Fixed): 
# Defended drop-in replacement
import defusedxml.ElementTree as ET
root_container = ET.fromstring(container_xml)

The path validation method (is_safe_path) permits reading any file in the user's home directory (~) as long as it's not hidden.

in_home = resolved.startswith(home_dir)

# Strictly scope to the project workspace data folder
workspace = os.getcwd()
allowed_dir = os.path.join(workspace, "data")
in_sandbox = resolved.startswith(allowed_dir)

10 • NiceGUI-FastAPI Loopback Loop Overhead

NiceGUI pages run inside the exact same OS process as FastAPI. However, NiceGUI fetches backend resources via HTTP loopback calls (127.0.0.1:8080).

Impact: Adds massive overhead due to network loopbacks, connection handshakes, and JSON serialization. Under moderate usage, pages lag while loading resources.
BEFORE: 
# In dashboard UI page
data = await APIClient.get("/resources/recent")
AFTER (Fixed): 
# Fetch directly bypassing HTTP stack
from backend.app.core.database import SessionLocal
from backend.app.api.resources import list_recent_resources

async def get_recent_resources_direct():
    with SessionLocal() as db:
        return list_recent_resources(db=db)
